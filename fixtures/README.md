# Synthetic demo evidence

The invoice, supplier-message, receiving, and credit files in this directory are fictional ClaimBack hackathon samples. North Star Pharma Distributors, Sharma Medical, and their document references are used only to exercise the demo workflow. No external supplier was contacted and no real credit was issued.

Within the demo scenario, an **issued credit note** or **posted invoice adjustment** is evidence of recovery. A supplier's promise to credit a future invoice is not. The files therefore use ordinary document wording for extraction, while this README and the public demo download page identify the samples as synthetic.

The full ₹3,218 credit and the ₹1,000 plus ₹2,218 partial path are alternatives. Upload only one branch for a given case.
